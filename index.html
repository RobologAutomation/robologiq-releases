For customers and the team: watch machines live, get alerts and receive reports by email.

Android

Phones and tablets with Android 7 or newer.

Download for Android
  1. Open the downloaded file.
  2. If Android asks, allow your browser to install apps, then tap Install.
  3. Later updates appear inside the app – tap Update now.

Windows

Windows 10 and 11. No administrator rights needed.

  1. Open PowerShell (Start menu → type "PowerShell").
  2. Paste this line and press Enter:
irm https://download.robologiot.co.in/install.ps1 | iex

It gets a Start-menu and desktop shortcut. Later updates appear inside the app.

RoboLogIQ Connect

Newest …

For installers: set up a Robolog Bridge on site over Bluetooth, test the readings and register it.

Android

Android phones with Bluetooth. Sign in with your installer account.

Download Connect for Android
  1. Open the downloaded file and tap Install (allow your browser to install apps if Android asks).
  2. On Samsung phones, turn off Auto Blocker first (Settings → Security).
  3. Later updates install inside the app: Account → Update.

What's new

Robolog Bridge firmware

Newest …

The software inside the Robolog Bridge (B100). Installers update it from RoboLogIQ Connect over Bluetooth; settings are kept.

Update a device

  1. Stand near the device and open RoboLogIQ Connect.
  2. Connect to the device, then tap Firmware.
  3. Tap Update and keep the phone close (about 15 minutes).

Connect checks the file before sending it. If an update stops part way, the device keeps its old firmware.
